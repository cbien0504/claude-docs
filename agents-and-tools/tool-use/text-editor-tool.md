## Tóm tắt

Claude có thể dùng text editor tool theo schema của Anthropic để xem và sửa file văn bản, giúp bạn gỡ lỗi, sửa và cải thiện code hoặc tài liệu văn bản khác. Nhờ đó Claude tương tác trực tiếp với file của bạn, hỗ trợ thực tế thay vì chỉ gợi ý thay đổi. Đây là client tool: ứng dụng của bạn triển khai việc thực thi các lệnh.

## Các điểm chính

- **Các lệnh của công cụ:** `view`, `str_replace`, `create`, `insert`.
- **Ví dụ trong trang:** sửa một lỗi cú pháp bằng text editor tool.
- **Triển khai:** xử lý lỗi và thực hành tốt khi triển khai.
- **Khác:** giá và mức dùng token, tích hợp với các công cụ khác, và nhật ký thay đổi (change log).

## Các mục trong trang gốc

Khi nào dùng text editor tool · Dùng text editor tool (các lệnh, ví dụ sửa lỗi cú pháp) · Triển khai text editor tool (xử lý lỗi, thực hành tốt) · Giá và mức dùng token · Tích hợp với công cụ khác · Nhật ký thay đổi · Các bước tiếp theo · Tính khả dụng.
