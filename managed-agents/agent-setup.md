## Tóm tắt

Agent là một cấu hình có thể tái sử dụng và có đánh phiên bản, định nghĩa persona và khả năng. Nó gói gọn mô hình, system prompt, công cụ, MCP server và skill, những thứ định hình cách Claude hành xử trong một session. Hãy tạo agent một lần như một tài nguyên tái sử dụng rồi tham chiếu bằng ID mỗi khi bắt đầu một session; agent có đánh phiên bản nên dễ quản lý qua nhiều session.

## Các điểm chính

- **Các trường cấu hình agent:** trang gốc có bảng liệt kê từng trường và mô tả.
- **Tạo agent**, kể cả cách ghim vị trí suy luận (inference geo).
- **Cập nhật agent**, kèm ngữ nghĩa của việc cập nhật.
- **Vòng đời agent:** liệt kê các phiên bản và lưu trữ (archive) agent.

## Các mục trong trang gốc

Các trường cấu hình agent · Tạo agent (ghim inference geo) · Cập nhật agent (ngữ nghĩa cập nhật) · Vòng đời agent (liệt kê phiên bản, lưu trữ agent) · Các bước tiếp theo · Tính khả dụng.
