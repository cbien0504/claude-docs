## Tóm tắt

Memory store cho agent bộ nhớ bền vững, tồn tại qua nhiều session. Trang mô tả cách tạo memory store, gắn vào session, xem và chỉnh sửa các memory, kiểm toán thay đổi và quản lý các store.

## Các điểm chính

- **Tạo memory store**, tùy chọn gieo sẵn nội dung ban đầu.
- **Gắn memory store vào session** và cách agent truy cập bộ nhớ.
- **Xem và chỉnh sửa memory:** liệt kê, đọc, tạo, cập nhật (có chỉnh sửa nội dung an toàn bằng kiểm soát đồng thời lạc quan, optimistic concurrency), và xóa.
- **Kiểm toán thay đổi:** liệt kê các phiên bản, lấy một phiên bản và che (redact) một phiên bản.
- **Quản lý memory store**, trong đó có liệt kê các store.
